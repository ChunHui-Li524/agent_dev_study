# Prompt Engineering 基础

Prompt Engineering 是通过设计输入提示来引导 LLM 输出质量的技术。

## 关键要素

- **System Prompt**：设定角色、语气、边界
- **User Prompt**：具体任务与约束
- **Few-shot**：提供示例引导格式

## 常用技巧

- 角色扮演：「你是 AI 技术导师…」
- 分步思考：「请分三步回答…」
- 输出格式：「以 JSON 输出…」

## 与微调对比

| 方式 | 适用场景 |
|------|----------|
| Prompt | 快速迭代、逻辑调整 |
| 微调 | 固定风格、领域深度适配 |
